# 루틴 & 식자재 관리 앱

하루 루틴(운동·할일)과 냉장고 식자재를 한곳에서 관리하는 모바일 웹 앱입니다.
별도 설치 없이 휴대폰 브라우저에서 바로 사용하며, 모든 데이터는 **기기 안(브라우저 저장소)에만** 저장됩니다. 서버나 로그인이 없습니다.

---

## 실행 방법

```bash
npm install      # 최초 1회
npm run dev      # 개발 서버 실행 (휴대폰에서도 접속 가능)
```

- 실행하면 터미널에 주소가 뜹니다. 같은 와이파이에 연결된 휴대폰 브라우저에서 `http://(컴퓨터IP):포트` 로 접속하세요.
- 화면이 휴대폰(세로) 화면 기준으로 디자인되어 있어, 휴대폰에서 가장 자연스럽게 보입니다.
- 홈 화면에 추가해두면 앱처럼 쓸 수 있습니다.

> 데이터는 사용하는 브라우저에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기/브라우저로 바꾸면 내용이 보이지 않습니다.

---

## 화면 구성

아래쪽 탭바의 4개 버튼으로 이동하거나, **화면을 좌우로 슬라이드**해서 탭을 넘길 수 있습니다.

| 탭 | 하는 일 |
|---|---|
| 📋 **플랜** | 날짜를 골라 그날 할 운동·할일을 체크 |
| 🏋️ **루틴** | 운동/할일 템플릿(반복할 것들)을 등록·관리 |
| 📊 **통계** | 주·월별 달성률 확인 |
| 🧺 **식자재** | 냉장고 식자재의 유통기한·수량 관리 |

---

## 1. 루틴 탭 — 반복할 것들 등록하기

매일 또는 자주 반복하는 운동과 할일을 미리 만들어 두는 곳입니다.

- **운동 태스크**: 운동 이름 + 세트 수 + 횟수(회) 또는 시간(초)을 등록합니다.
- **운동 그룹**: 여러 운동을 묶어 하나의 루틴으로 만듭니다. (예: "상체의 날" = 푸시업 + 풀업)
- **일반 그룹**: 운동이 아닌 반복 할일을 묶습니다. (예: "아침 루틴" = 물 마시기, 영양제)

> **꿀팁**: 세트·횟수 옆 `−` / `+` 버튼은 **길게 누르고 있으면** 숫자가 계속 빠르게 바뀝니다. 큰 숫자도 한 번에!

항목을 누르면 상세 화면이 열려 수정·삭제할 수 있습니다.

---

## 2. 플랜 탭 — 오늘 할 것 체크하기

- 위쪽에서 **날짜를 선택**합니다.
- 루틴 탭에서 만든 운동 그룹·일반 그룹을 그날에 적용하고, 세트/항목을 하나씩 체크합니다.
- **운동 중 타이머**
  - 세트를 완료하면 **휴식 타이머(60초)**가 화면 위에 표시됩니다.
  - "초"로 설정한 운동은 세트별 **운동 시간 타이머**가 자동으로 흐르고, 목표 시간을 넘기면 빨갛게 표시됩니다.
  - 완료 시 알림음이 울립니다.

---

## 3. 통계 탭 — 얼마나 했는지 보기

- 주차/월 단위로 운동·할일의 **달성률**을 막대와 수치로 보여줍니다.
- 좌우 스와이프로 주차를 넘길 수 있고, 항목을 누르면 기록 히스토리를 펼쳐 볼 수 있습니다.

---

## 4. 식자재 탭 — 냉장고 관리하기

집에 있는 식자재의 유통기한과 수량을 관리합니다.

### 등록하기
1. 아래 **`+ 식자재 추가`** 를 누르면 입력 화면이 열립니다.
2. **이름**을 적습니다.
3. **보관 장소**(상온 / 냉장고 / 냉동실)를 고릅니다.
4. **유통기한**: `YYYY.MM.DD` 칸을 누르면 작은 달력이 뜹니다. 날짜를 고르면 자동 입력됩니다. (위아래로 넘겨 다른 달 이동, "없음"으로 비울 수 있음)
5. **수량**: 칸을 누르면 휠이 뜹니다. 위아래로 굴려서 개수를 정합니다. (튕기면 관성으로 쭉 굴러감, 최소 1개)
   - **소수 단위 사용**을 체크하면, 나중에 사용할 때 0.2개씩 덜어낼 수 있습니다. (예: 두부 한 모를 0.4개씩)
6. **추가**를 누릅니다.

### 목록 보기
- **유통기한이 임박한 순서**로 정렬됩니다.
- 왼쪽 배지로 남은 날짜를 알려줍니다: `D-3`, `오늘`, `지남` 등. 임박할수록 배지가 빨개집니다.
- 보관 장소가 회색 배지로 함께 표시됩니다.

### 사용하기 / 수정하기
목록의 항목을 누르면 상세 화면이 열립니다.

- **남은 수량**을 `−` / `+` 로 조절합니다. (소수 항목은 0.2개, 일반 항목은 1개 단위 / **길게 누르면 연속 조절**)
- 이름·보관·유통기한·소수 단위도 여기서 모두 바꿀 수 있습니다.
- **다 쓰면**: 수량을 `0개`로 만들면 "0개 되면 삭제됩니다" 경고가 뜨고, **완료** 시 목록에서 자동으로 사라집니다.
- 그냥 지우고 싶으면 **삭제** 버튼을 누릅니다.

---

## 자주 묻는 것

- **데이터가 사라졌어요** → 브라우저 저장소에만 있기 때문에, 방문 기록/캐시를 지우면 함께 지워집니다. 시크릿(비공개) 탭에서도 저장이 유지되지 않습니다.
- **다른 폰에서도 보고 싶어요** → 현재는 기기별로 따로 저장됩니다. (동기화 기능 없음)
- **인터넷이 필요한가요?** → 처음 화면을 불러올 때만 필요하고, 데이터 자체는 오프라인으로 기기에 저장됩니다.
